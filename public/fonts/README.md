# Self-hosted fonts

Latin-subset variable woff2 files, downloaded unmodified from Google Fonts
(the Google Fonts CDN) so the site makes no third-party font requests.

| File | Family | Weights used | Licence |
|---|---|---|---|
| `cinzel-latin.woff2` | Cinzel (v26) | 500, 700, 900 | SIL OFL 1.1 - `OFL-Cinzel.txt` |
| `inter-latin.woff2` | Inter (v20) | 300-700 | SIL OFL 1.1 - `OFL-Inter.txt` |

Characters outside the Latin range fall back to the system font stack.
